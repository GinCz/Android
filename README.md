## 🧭 Каталог официальных Android-приложений (.apk)

Публичный репозиторий официальных релизов мобильных и Smart TV приложений экосистемы **GinCz + Anti-Gravity AI**.

Каждое приложение распространяется в виде готового актуального APK-файла без сторонней рекламы, трекеров и подписок:

| Приложение | Файл пакета (.apk) | Назначение и ключевые возможности | Релиз |
| :--- | :--- | :--- | :---: |
| 🎬 **[GIN-Cinema ↗](GIN-Cinema/)** | [**`GIN-Cinema.apk` ↗](GIN-Cinema/GIN-Cinema.apk) | Онлайн-кинотеатр с поддержкой 4K HDR, аппаратным декодером ExoPlayer и адаптацией под пульты Android TV. | 🟢 `v114` (Active) |
| 📺 **[GIN-TV ↗](GIN-TV/)** | [**`GIN-TV.apk` ↗](GIN-TV/GIN-TV.apk) | Высокоскоростной плеер онлайн-ТВ и IPTV с переключением каналов за 0.3с и встроенной телепрограммой (EPG). | 🟢 `v077` (Active) |
| 🌐 **[GIN-IP ↗](GIN-IP/)** | [**`GIN-IP.apk` ↗](GIN-IP/GIN-IP.apk) | Диагностика сетевых подключений, определение внешнего IP, провайдера, ASN и тест задержки DNS в 1 касание. | 🟢 `v013` (Active) |
| 📦 **[GIN-APP ↗](GIN-APP/)** | [**`GIN-APP.apk` ↗](GIN-APP/GIN-APP.apk) | Единый хаб и портал приложений экосистемы GinCz с фоновым автообновлением установленных программ. | 🟢 `v006` (Active) |

## ⚡ Политика Единственного Актуального Релиза

Каждый каталог проекта содержит **ровно один файл APK актуальной сборки** со стабильным именем для обеспечения бесшовного автоматического обновления (`self-updater`). Детальная хронология изменений и разбор архитектурных решений зафиксированы в соответствующих файлах `CHANGELOG.md`.

*Все полные исходные коды (Kotlin, Java, Gradle build environments) надежно хранятся в приватном хранилище разработчика.*
