## 🎯 Overview
Native Android mobile client for the **Ultarix-Monitor** infrastructure.
Provides real-time monitoring of all office workstations, active tasks, software usage (STEREO, Ekonom.win, Excel, Chrome), and AFK pauses from anywhere in the world.
