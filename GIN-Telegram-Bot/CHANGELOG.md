## [v001-plan] — 2026-11-28
### Added
- Initial open-source public specification and architecture design.
- Dual-SIM SMS interception engine (SmsBroadcastReceiver) with slot detection.
- App notification listener module (NotificationListenerService) with interactive package checklist.
- Uptime Kuma push heartbeat integration with battery and Wi-Fi RSSI reporting.
- Offline SQLite buffer queue for network failure resilience.
- Native lightweight HTTP client design without Google Play Services dependencies.
